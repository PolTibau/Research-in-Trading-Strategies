# Research in Trading Strategies

This repository focuses on exploring **improvements to classic trading strategies** by incorporating **sentiment data** extracted using **NLP from newspapers and daily processed news**. The goal is to analyze how sentiment can enhance traditional models and optimize their performance.

## 📌 Contents
- 📊 **Sentiment Analysis in Trading**: Extracting market sentiment from financial news and media.
- 🔍 **Enhancing Classic Trading Strategies**: Integrating sentiment data into well-known trading models.
- 📈 **Backtesting with Backtrader**: Using the **Backtrader** library to evaluate strategy performance.
- 📉 **Hyperparameter Optimization with Optuna**: Optimizing strategy parameters using **Optuna**.
- 🛠️ **Data Collection & Processing**: Automating data retrieval and preprocessing for sentiment analysis.

## 🚀 Getting Started

### Prerequisites
To run the code and experiments in this repository, you will need:
- Python 3.x
- Jupyter Notebook (optional but recommended)
- The following Python libraries:
  ```sh
  pip install pandas numpy matplotlib backtrader optuna
  ```
